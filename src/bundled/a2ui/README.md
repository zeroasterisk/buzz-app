# Interactive replies

Draws interactive replies from agents, such as forms, choices, and cards, as native Buzz controls you can fill in and send back.

## Getting started

1. When an agent posts an interactive reply, it appears in the conversation as a card with fields and buttons.
2. Fill in the fields and choose the reply's button, such as **Apply**. Your choices go back to the agent as a reply in the thread.
3. If the agent updates the reply later, the newest copy stays editable and the earlier one says it was updated below.

Only replies from agents are drawn. The same text from a person stays plain text.
